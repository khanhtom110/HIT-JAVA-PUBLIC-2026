1. List và ArrayList

Khái niệm: List là interface dùng để lưu trữ dữ liệu theo thứ tự, cho phép truy cập bằng chỉ số. ArrayList là lớp triển khai phổ biến nhất của List. Khi cần lưu nhiều phần tử nhưng không biết trước số lượng, ArrayList là lựa chọn tiện lợi và dễ dùng.

Đặc điểm chính của List

  • Giữ nguyên thứ tự các phần tử khi thêm vào.
  • Cho phép truy cập phần tử theo vị trí index.
  • Cho phép phần tử trùng lặp.
  • Có thể thay đổi kích thước khi cần thêm hoặc xóa phần tử.
  • Thường được sử dụng trong các bài toán quản lý danh sách, sinh viên, sản phẩm, điểm số, ...

Cách khai báo và khởi tạo

import java.util.ArrayList;
import java.util.List;

List<String> sinhVien = new ArrayList<>();
Chú ý: Khi khai báo biến, nên dùng kiểu List để code dễ mở rộng hơn. Khi cần khởi tạo đối tượng cụ thể, mới dùng new ArrayList<>().

Ví dụ cho từng phương thức của List/ArrayList

1. add(): thêm phần tử

List<String> danhSach = new ArrayList<>();
danhSach.add("An");
danhSach.add("Binh");
danhSach.add("Cuong");
System.out.println(danhSach); // [An, Binh, Cuong]

2. get(): lấy phần tử theo vị trí

List<String> danhSach = new ArrayList<>();
danhSach.add("An");
danhSach.add("Binh");
System.out.println(danhSach.get(0)); // An
System.out.println(danhSach.get(1)); // Binh

3. set(): thay đổi giá trị ở vị trí đã có

List<String> danhSach = new ArrayList<>();
danhSach.add("An");
danhSach.add("Binh");
danhSach.set(1, "Duy");
System.out.println(danhSach); // [An, Duy]

4. remove(): xóa phần tử

List<Integer> so = new ArrayList<>();
so.add(10);
so.add(20);
so.add(30);
so.remove(1);
System.out.println(so); // [10, 30]

5. size(): lấy số lượng phần tử

List<String> danhSach = new ArrayList<>();
danhSach.add("A");
danhSach.add("B");
danhSach.add("C");
System.out.println(danhSach.size()); // 3

6. contains(): kiểm tra phần tử có tồn tại hay không

List<String> danhSach = new ArrayList<>();
danhSach.add("Java");
danhSach.add("C++");
System.out.println(danhSach.contains("Java")); // true
System.out.println(danhSach.contains("Python")); // false

7. indexOf(): tìm vị trí đầu tiên của phần tử

List<String> danhSach = new ArrayList<>();
danhSach.add("Java");
danhSach.add("PHP");
danhSach.add("Java");
System.out.println(danhSach.indexOf("Java")); // 0

8. isEmpty(): kiểm tra danh sách có rỗng không

List<String> danhSach = new ArrayList<>();
System.out.println(danhSach.isEmpty()); // true

danhSach.add("Java");
System.out.println(danhSach.isEmpty()); // false

So sánh List/ArrayList với mảng

  • Mảng có kích thước cố định, còn ArrayList có thể tăng hoặc giảm theo nhu cầu.
  • Mảng chỉ lưu dữ liệu cùng kiểu, còn List có thể quản lý linh hoạt hơn trong quá trình code.
  • ArrayList hỗ trợ nhiều phương thức tiện ích như add, remove, set, contains, size,...
Chú ý: Với dữ liệu dạng số nguyên, nếu dùng ArrayList thì cần dùng Integer thay vì int. Vì Integer là kiểu đối tượng, còn int là kiểu nguyên thủy.

2. Static trong Java

Khái niệm: Từ khóa static được dùng để khai báo thành viên thuộc về class, không thuộc về đối tượng riêng lẻ. Nghĩa là dù bạn tạo bao nhiêu đối tượng, biến hoặc phương thức static chỉ có một bản duy nhất và được chia sẻ cho toàn bộ object của class.

Biến static

Biến static thường được dùng để lưu thông tin chung cho mọi đối tượng như tên trường, số lượng sinh viên, trạng thái hệ thống, ... 

class SinhVien {
    String ten;
    static String truong = "HIT";

    public void inThongTin() {
        System.out.println("Ten: " + ten + ", Truong: " + truong);
    }
}

public class DemoStatic {
    public static void main(String[] args) {
        SinhVien sv1 = new SinhVien();
        sv1.ten = "An";

        SinhVien sv2 = new SinhVien();
        sv2.ten = "Binh";

        System.out.println(sv1.truong); // HIT
        System.out.println(sv2.truong); // HIT
    }
}

Phương thức static

Phương thức static thường dùng để viết các chức năng chung, không phụ thuộc vào dữ liệu của đối tượng cụ thể. 

class MathUtil {
    public static int tinhTong(int a, int b) {
        return a + b;
    }
}

public class DemoStaticMethod {
    public static void main(String[] args) {
        int ketQua = MathUtil.tinhTong(10, 20);
        System.out.println(ketQua); // 30
    }
}

Khối static

Khối static được thực thi một lần khi class được nạp vào bộ nhớ, trước khi chương trình chạy các phần khác. 

class DemoStaticBlock {
    static int x;

    static {
        x = 100;
        System.out.println("Khối static chạy lần đầu");
    }

    public static void main(String[] args) {
        System.out.println("x = " + x);
    }
}
Chú ý:
  • Phương thức static không thể truy cập biến instance trực tiếp.
  • Phương thức static không thể sử dụng this hoặc super.
  • Biến static được chia sẻ cho tất cả đối tượng của class.

3. Từ khóa this trong Java

Khái niệm: this là tham chiếu đến đối tượng hiện tại đang được thực thi trong class. Nó giúp Java phân biệt rõ giữa biến của đối tượng và biến local hoặc tham số truyền vào.

Khi nào nên dùng this?

  • Khi tên biến instance trùng với tên tham số của constructor hoặc phương thức.
  • Khi cần gọi constructor khác trong cùng class.
  • Khi cần truy cập dữ liệu của đối tượng hiện tại.

Ví dụ 1: Dùng this để phân biệt biến và tham số

class SinhVien {
    String ten;

    SinhVien(String ten) {
        this.ten = ten;
    }

    void inThongTin() {
        System.out.println("Ten: " + this.ten);
    }
}

public class DemoThis {
    public static void main(String[] args) {
        SinhVien sv = new SinhVien("Lan");
        sv.inThongTin();
    }
}

Ví dụ 2: Dùng this() để gọi constructor khác

class HinhChuNhat {
    int chieuDai;
    int chieuRong;

    HinhChuNhat() {
        this(10, 20);
    }

    HinhChuNhat(int chieuDai, int chieuRong) {
        this.chieuDai = chieuDai;
        this.chieuRong = chieuRong;
    }

    void inKichThuoc() {
        System.out.println(this.chieuDai + " x " + this.chieuRong);
    }
}

public class DemoThisConstructor {
    public static void main(String[] args) {
        HinhChuNhat hcn = new HinhChuNhat();
        hcn.inKichThuoc(); // 10 x 20
    }
}
Chú ý:
  • this không thể được dùng bên trong phương thức static.
  • this() chỉ dùng để gọi constructor khác trong cùng class.
  • this thường dùng để tránh nhầm lẫn giữa biến instance và tham số.

4. Nạp chồng phương thức (Method Overloading)

Khái niệm: Nạp chồng phương thức là kỹ thuật cho phép một class định nghĩa nhiều phương thức cùng tên nhưng khác nhau về số lượng tham số hoặc kiểu dữ liệu tham số. Java sẽ tự động chọn phương thức phù hợp khi bạn gọi nó.

Điều kiện để nạp chồng phương thức

  • Cùng tên phương thức.
  • Khác số lượng tham số, hoặc kiểu tham số.
  • Không được chỉ khác nhau ở kiểu trả về.

Ví dụ minh họa

class TinhToan {
    int cong(int a, int b) {
        return a + b;
    }

    double cong(double a, double b) {
        return a + b;
    }

    int cong(int a, int b, int c) {
        return a + b + c;
    }
}

public class DemoOverloading {
    public static void main(String[] args) {
        TinhToan tt = new TinhToan();

        System.out.println(tt.cong(2, 3));       // 5
        System.out.println(tt.cong(2.5, 3.5));   // 6.0
        System.out.println(tt.cong(1, 2, 3));    // 6
    }
}
Chú ý:
  • Nạp chồng khác với override.
  • Nạp chồng xảy ra trong cùng class.
  • Override xảy ra giữa lớp cha và lớp con.
  • Khi gọi phương thức, Java sẽ chọn phiên bản phù hợp với tham số được truyền vào.

5. Bài tập tổng hợp

Bài 1 Quản lý sinh viên trong lớp học
Tạo class SinhVien với thuộc tính: maSV, ten, diemToan, diemLy, diemHoa. Viết constructor rỗng và constructor có tham số. Dùng this để gán giá trị. Sau đó tạo một ArrayList để lưu 5 sinh viên, in danh sách ra màn hình, tính điểm trung bình mỗi người và in ra sinh viên có điểm cao nhất.
Bài 2 Hệ thống quản lý sản phẩm
Tạo class SanPham gồm: ten, gia, soLuong, và biến static bienDem. Viết phương thức themSanPham() để cộng số lượng, phương thức tinhTien() để tính tổng tiền, và phương thức inThongTin() để in thông tin sản phẩm. Sau đó tạo 3 sản phẩm khác nhau, tính tổng giá trị hàng hóa và in ra số lượng sản phẩm đã được thêm.
Bài 3 Máy tính mini + nạp chồng phương thức
Viết class Calculator có các phương thức:
- cong(int a, int b)
- cong(double a, double b)
- cong(int a, int b, int c)
- tinhTong(List<Integer> ds)
Gọi từng phương thức, in kết quả và kiểm tra xem khi truyền danh sách số nguyên, chương trình có thể tính tổng đúng không.
